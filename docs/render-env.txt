CONFIGURACIÓN DEL WEB SERVICE
==============================

En Render → New Web Service → Settings:

1. Root Directory: backend

2. Build Command: pip install -r requirements.txt

3. Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT

4. HTTP Port: 8000  ← esto va en el campo "HTTP Port" de Render, NO en el Start Command


ANTES DEL DEPLOY EN RENDER
===========================

2. Pega el contenido de backend/supabase_schema.sql y ejecútalo
3. Luego ve a: https://<tu-app>.onrender.com/admin/api/setup
